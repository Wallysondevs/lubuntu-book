# Lubuntu: Do Zero ao Domínio

  Livro completo de Lubuntu em português, com 90+ capítulos cobrindo LXQt, hardware leve, instalação, personalização, terminal, pacotes, rede, manutenção e projetos práticos.

  **Online:** https://wallysondevs.github.io/lubuntu-book/

  ## Stack

  - Vite + React 19 + TypeScript
  - Tailwind CSS v4
  - Wouter (hash routing)
  - Framer Motion + Lucide Icons

  ## Desenvolvimento

  ```bash
  npm install
  npm run dev
  npm run build
  ```

  ## Deploy (GitHub Pages)

  ```bash
  npm run build
  npm run deploy
  ```
